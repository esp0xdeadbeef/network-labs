# FS-166-HDS-010-SDS-010

SDS template row for the active-lab renderer-entry mini POCs.

This row exposes each renderer-input variant as its own concrete SMS trace
(`FS-166-HDS-010-SDS-010-SMS-901` through
`FS-166-HDS-010-SDS-010-SMS-906`) so agents can grep and run individual
renderers with small CPM inputs instead of deploying HAT or SAT.
