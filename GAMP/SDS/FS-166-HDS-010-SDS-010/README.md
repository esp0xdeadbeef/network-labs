# FS-166-HDS-010-SDS-010

This lab source implements the controlled layer-entry architecture defined by
the canonical SDS in `network-codex-agent`.

The validation scheme invokes every repository hop. A contiguous skipped
prefix emits repository-owned acknowledgements, while the replacement artifact
enters the input of the first normally executed semantic stage exactly once.
Renderer-bound scenarios continue through realization, schema validation, one
normalized platform-binding bundle, and the selected renderer.

SMS-010 validates controlled-skip acknowledgements. SMS-020 validates control
flow and boundary-dependent artifact flow. SMS-030 validates evidence scope and
privacy handling. SMS-901 through SMS-906 are concrete controlled replacement
scenarios; they are not direct CPM-to-renderer fixtures.
